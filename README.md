# multi-axis_AM_partorientation
This repository contains the source code for the paper titled 'A salient vector field-driven part orientation selection for multi-axis 3D printing', Computer-Aided Design, Volume 184, July 2025, 103877 - https://doi.org/10.1016/j.cad.2025.103877

curvedslicing_RBF folder contains the code to generate RBF-weighted print sequence scalar field, as proposed by the paper titled 'Convexity and Surface Quality Enhanced Curved Slicing for Support-Free Multi-Axis Fabrication' https://doi.org/10.3390/jmmp7010009 - 

**** PLEASE CITE THE RELATED PAPER FROM ABOVE IF YOU'RE USING THE FULL OR PART OF CODE PROVIDED IN THIS REPO ***

Instructions:

Download the dependency: GPtoolbox [https://uk.mathworks.com/matlabcentral/fileexchange/49692-gptoolbox] in to your local repo.
Before running the code, please create a folder called 'Libraries' in your local repo, and ensure both the 'GPtoolbox' and 'functions' folders are inside of it.
Note- this is an initial demo version.
